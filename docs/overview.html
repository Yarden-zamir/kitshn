3 · The offline page of a live site

Shown when the machine or the local server of a live site is off (K-1106). It comes from the kitshn Worker's static assets, with no call to the machine.

Last seen 12 minutes ago · served by kitshn
How kitshn knows
Machine off: its daemon socket closes, or misses pings for 30 s.
Local server off: the daemon tries the socket every 10 s, on the machine, and reports a change (K-1107).
How it stays free
Only while the origin is down, kitshn adds a Worker route for that address. Healthy visits never run the Worker. The Worker still tries the origin first, so a site that is back works at once (K-1108, K-1109).

Status 503 with Retry-After 60. No auto reload, no continuous animation. Custom error rules would need no Worker, but the free plan has none.

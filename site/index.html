Sharing

Share it in one drag

Add a friend's email to a circle once. From then on, sharing anything with them is a drag, and they sign in with a code that lands in their inbox. No passwords, and nobody makes an account.

  • ✉️

    Just an email

    Put a friend in a circle by their email. They need no account, no app and no password.

  • 👆

    Drag in, drag out

    Drop a project into a circle to share it. Drag it out again, and their access ends.

  • ⏱

    Shares that end on their own

    Give a guest a week. The share ends by itself, and nobody has to remember.

Projects

Sites, apps and containers, one workflow

One repo, one recipe, one push. This trip planner has a site, an API and a photo album, and each part runs where it fits best.

git push to main deploys, in this order:

  1. worker

    api · the trip API

    A Cloudflare Worker. It keeps the plans in KV, and a cron runs it every morning at 7:00.

  2. compose

    photos · the photo album

    Docker Compose on your home machine, behind its tunnel, with backups of its volumes.

  3. static

    web · the site

    Static files on Workers, where requests are free, at trip.you.dev. It starts in Friends, after the API it needs.

Each pull request also gets its own preview of the site, gone when it closes.

Self-hosting

Your home server, on the internet, with no open ports

A small daemon joins each machine with one command. It runs the tunnel, deploys Compose apps in rootless Docker, and shares local dev servers as live sites.

  • No open ports: every machine talks through its tunnel.
  • When a machine is off, visitors get a friendly offline page instead of an error. It costs a Worker request only while the site is down.
Safety

No keys to copy, no secrets to leak

Your repo holds no Cloudflare token, no deploy key, no password. Each push proves who it is, and kitshn checks it before anything goes live.

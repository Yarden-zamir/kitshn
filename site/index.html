Self-hosting

Run it at home. Open it from anywhere.

Got an old PC, a Raspberry Pi or a home server? Join it to kitshn with one command, and the apps on it get their own web addresses. Your router stays closed.

  1. 1

    Your machine opens the tunnel

    A small program calls out to the cloud and keeps the line open. Outgoing only, so there's nothing to set up on your router.

  2. 2

    Visitors come in through it

    The cloud checks who they are first. Only the people you shared with get through to your machine.

  • No port forwarding, and no public IP needed
  • Docker Compose apps run in rootless Docker
  • Volumes get encrypted backups every night
  • Share a dev server with kitshn expose 5173
  • Linux and macOS run containers; Windows shares dev servers
  • When a machine is off, visitors get a friendly page
Safety

Your projects, safe and secure

You never keep a password in your code. Every update is checked before it goes live, and every visitor is checked before they get in.
